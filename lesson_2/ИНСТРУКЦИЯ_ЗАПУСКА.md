# Как запустить Lecture_2.ipynb

Ноутбук можно запустить на своём компьютере в PyCharm, VS Code или другой IDE с поддержкой Jupyter, а также в Google Colab через браузер.

## 1. Проверьте, что у вас есть все файлы

Для занятия нужны:

- `Lecture_2.ipynb` — ноутбук с материалами и кодом;
- `data.csv` — датасет;
- `boxplot_explained.png` — изображение с объяснением боксплота;
- `requirements.txt` — список библиотек для установки на своём компьютере.

На своём компьютере положите эти файлы в одну папку, например, под названием `занятие_2`:

```text
занятие_2/
├── Lecture_2.ipynb
├── data.csv
├── boxplot_explained.png
└── requirements.txt
```

Не переименовывайте датасет и изображение: в ноутбуке используются именно эти имена.

## 2. Запуск на своём компьютере

**Как это сделать, объясняется в конце записи первой лекции.**

Убедитесь, что на компьютере установлен Python. Для занятия можно использовать Python 3.12.

Откройте папку, в которую вы поместили файлы, в своей IDE. Затем откройте встроенный терминал. Все команды ниже выполняйте из этой папки.

### Создайте виртуальное окружение

Виртуальное окружение (`venv`) — отдельная папка с Python и библиотеками для этого занятия.

**Windows:**

```powershell
py -m venv .venv
```

**macOS / Linux:**

```bash
python3 -m venv .venv
```

После выполнения команды появится папка `.venv`.

### Активируйте окружение

**Windows, PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
```

**Windows, командная строка (cmd):**

```bat
.venv\Scripts\activate.bat
```

**macOS / Linux:**

```bash
source .venv/bin/activate
```

После активации в начале строки терминала обычно появляется `(.venv)`.

Если PowerShell запрещает запуск скрипта активации, откройте терминал cmd и используйте команду для него, приведённую выше.

### Установите библиотеки

В терминале с активированным окружением выполните:

```bash
python -m pip install -r requirements.txt matplotlib ipykernel
```

`matplotlib` нужен для графиков, а `ipykernel` — для выполнения ячеек ноутбука. Их устанавливаем явно в дополнение к `requirements.txt`.

### Выберите окружение в IDE

**VS Code:**

1. Установите расширения **Python** и **Jupyter** от Microsoft.
2. Откройте `Lecture_2.ipynb`.
3. Нажмите выбор ядра (**Select Kernel**) в верхней части ноутбука.
4. Выберите Python из созданной папки `.venv`.

**PyCharm:**

1. В настройках интерпретатора проекта выберите существующее окружение `.venv`.
2. Путь к интерпретатору: `.venv\Scripts\python.exe` на Windows или `.venv/bin/python` на macOS / Linux.
3. Откройте `Lecture_2.ipynb` и выберите это окружение для выполнения ячеек. Ваша версия PyCharm должна поддерживать Jupyter-ноутбуки.


### Запустите ячейки

Выполняйте ячейки сверху вниз кнопкой запуска или сочетанием **Shift + Enter**. Можно выполнить весь ноутбук командой **Run All**.

Рабочей папкой ядра должна быть папка, в которой находятся ноутбук и датасет `data.csv`. Название папки может быть любым. Это важно, потому что в ноутбуке указан относительный путь к датасету: `DATA_PATH = "data.csv"`.

Если возникает ошибка `FileNotFoundError`, проверьте рабочую папку ядра, выполнив в отдельной ячейке:

```python
from pathlib import Path
print(Path.cwd())
```

Если датасет находится в другой папке, измените `DATA_PATH`, указав путь к нему.

## 3. Запуск в Google Colab

В Colab не нужно создавать `venv`, активировать окружение или устанавливать Python на компьютер. Основные библиотеки для этого ноутбука уже доступны.

1. Откройте **Google Colab** в браузере.
2. Загрузите и откройте `Lecture_2.ipynb` через пункт загрузки ноутбука.
3. Откройте панель **Файлы** слева.
4. Загрузите туда `data.csv` и `boxplot_explained.png`. Они должны находиться в рабочей папке `/content`, без дополнительной вложенной папки.
5. Выполняйте ячейки сверху вниз с помощью **Shift + Enter** или выберите запуск всех ячеек в меню среды выполнения.

**Загруженные файлы хранятся временно. Если Colab создаст новую среду выполнения, загрузите датасет и PNG повторно.**

Если Colab не показывает PNG в текстовой ячейке, добавьте кодовую ячейку и выполните:

```python
from IPython.display import Image, display
display(Image(filename="/content/boxplot_explained.png"))
```

По любым вопросам можете писать в общий чат курса.
