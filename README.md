# оценка стоимости квартиры

простое приложение на Streamlit с двумя обученными моделями:

- линейная регрессия предсказывает стоимость квартиры в рублях;
- логистическая регрессия определяет класс: `0` означает не выше рынка, `1` означает выше рынка.

выберите задачу в боковой панели и загрузите CSV или Excel (`.xlsx`) с параметрами одной или нескольких квартир. все 19 обязательных полей описаны в приложении. результат можно скачать в CSV.

классификация выполняется по параметрам квартиры без цены объявления. классы основаны на учебных городских ориентирах из занятия 4 и не являются проверкой конкретной цены на текущем рынке.

## структура репозитория

```text
app.py                    # интерфейс, загрузка данных и предсказания
requirements.txt          # зависимости приложения
models/
    price_model.pkl       # модель предсказания цены
    class_model.pkl       # классификатор вместе с масштабированием
README.md                 # описание и запуск
```

модели уже обучены и загружаются из `models/` без повторного обучения.

## запуск

из папки репозитория с активированным виртуальным окружением:

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

для публикации в Streamlit Community Cloud выберите репозиторий, нужную ветку и файл `app.py`.
