# Занятие 5. Метрики классификации

Откройте `Lecture_5.ipynb` в VS Code с расширениями Python и Jupyter. Выберите Python-окружение с пакетами из `requirements.txt` и выполните все ячейки сверху вниз. При необходимости: `%pip install -r requirements.txt` из ячейки ноутбука, если ядро запущено из этой папки.

Ноутбук продолжает занятие 4: краткое повторение классификации и log loss, подробные precision и recall, кратко F1 и дисбаланс, изменение порога и практика на квартирах. Готовые результаты сохранены в ноутбуке.

`threshold_kitty.html` — автономная интерактивная панель с ползунком, котиками, матрицей ошибок и графиками метрик. Открывается обычным браузером, без интернета и Python. Если VS Code блокирует JavaScript внутри ноутбука, используйте этот файл. При необходимости запуск браузера через локальный сервер: `python -m http.server 8000`, затем `http://localhost:8000/threshold_kitty.html`.

`images/threshold_kitty.png` — статическая памятка для порогов 0.2, 0.5, 0.9. Она также выводится кодом внутри ноутбука.

`data/data.csv` — копия таблицы занятия 4 (5491 строка, цель `above_market`). Перед разбиением ноутбук удаляет 372 точных дубликата; остаётся 5119 строк. Идентификаторов объявлений нет: удаление точных повторов не гарантирует разделения разных объявлений одной квартиры. Цель уже задана в исходных материалах, ценовые признаки в X не включены.

Правило везде одно: `p > t` даёт класс 1, при равенстве — 0. Для неопределённой precision используется условный 0 (`zero_division=0`), что отдельно объясняется в тексте. Порог выбирается на validation; test используется после фиксации решения.


## две модели и приложение

`Train_models.ipynb` обучает линейную и логистическую регрессию по примеру занятий 3 и 4, проверяет их на test и сохраняет `models/price_model.pkl` и `models/class_model.pkl`. scaler классификатора находится внутри сохранённого pipeline. строки с одинаковыми признаками разделяются группами, чтобы исключить их пересечение между train и test. цену и её производные модели не получают.

`data/price_data.csv` скопирован из занятия 3 для обучения регрессии. классификация использует `data/data.csv`. ноутбук работает из корня курса или папки занятия. модели уже обучены, повторное выполнение ноутбука нужно только для их обновления.

запуск из корня курса:

```bash
python -m pip install -r занятие_5/requirements.txt
python -m streamlit run занятие_5/app.py
```

в боковой панели выберите задачу и загрузите файл с параметрами. примеры находятся в папке data/. `data/example_apartments.csv` содержит три примера и все 19 нужных полей. приложение поддерживает одну или несколько квартир, показывает результат и позволяет скачать его в csv. лишние столбцы игнорируются. для цены результат указан в рублях, для классификации выводятся 0 или 1 и текстовый ответ.

классификатор, как в занятии 4, предсказывает класс по характеристикам без цены объявления. он не проверяет конкретную запрошенную продавцом сумму. «выше рынка» означает учебный класс по заранее заданным городским ориентирам, а не подтверждённую переоценку на текущем рынке. для студий rooms = 0, для Дербента все city_ = 0, для базового типа дома все «Тип дома_» = 0.

для загрузки pickle нужна та же версия scikit-learn, что при обучении: 1.8.0, она указана в requirements.txt. приложение открывает только собственные файлы моделей из models/.

в исходных данных passenger_lift_count = -1 обозначает неизвестное число лифтов, приложение принимает этот код.


## примеры excel

приложение принимает csv и xlsx, первый лист excel должен содержать заголовки в первой строке.

- `data/example_regression.xlsx`: три квартиры из `data/price_data.csv`, строки данных 1, 2 и 3.
- `data/example_classification.xlsx`: три квартиры из `data/data.csv`, строки данных 1, 5 и 9. в исходных данных есть оба класса.

каждый файл содержит только 19 входных признаков моделей, без цены, цены за м² и правильного класса. значения взяты из исходных таблиц без изменений. для проверки приложения загрузите соответствующий пример из папки data/.
