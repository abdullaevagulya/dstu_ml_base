# Основы анализа данных и ML для начинающих

Курс подготовлен для студентов Дагестанского государственного технического университета (ДГТУ). Его цель - дать базовое понимание Data Science, Artificial Intelligence и Machine Learning, а также показать полный путь от анализа данных до простого ML-приложения.

В рамках курса студенты познакомятся с основными типами задач машинного обучения, научатся работать с данными, строить базовые модели, оценивать их качество и оформлять результат в виде проекта для GitHub.

Курс на Stepik: https://stepik.org/course/297193/info

## План курса

1. **Вводная лекция**
   - что такое AI, ML, DL и Data Science;
   - какие задачи решает машинное обучение;
   - знакомство с инструментами для работы с данными.

2. **Анализ данных**
   - работа с реальными данными недвижимости;
   - первичный анализ данных;
   - очистка, обработка и визуализация данных.

3. **Регрессия**
   - задача предсказания числового значения;
   - подготовка данных для модели;
   - обучение и оценка модели регрессии.

4. **Классификация**
   - задача предсказания категории;
   - подготовка данных для классификации;
   - оценка качества классификационной модели.

5. **Финальный проект**
   - знакомство со Streamlit;
   - разработка приложения для предсказания цены квартиры;
   - оформление проекта в GitHub.

## Итог курса

По итогам курса студенты подготовят финальный проект: Streamlit-приложение, которое использует модель машинного обучения для предсказания цены квартиры на основе входных параметров.
